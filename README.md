## Deskripsi
Program Python untuk menghitung nilai akhir mahasiswa dan menentukan
status kelulusan berdasarkan nilai tugas, UTS, UAS, dan persentase kehadiran.

## Rumus Nilai Akhir
Nilai Akhir = (20% x Tugas) + (30% x UTS) + (50% x UAS)

## Ketentuan Status
- **LULUS DENGAN PREDIKAT**: nilai akhir >= 85, kehadiran >= 90%, dan nilai akhir genap
- **LULUS**: nilai akhir >= 75 dan kehadiran >= 80%
- **BELUM LULUS**: jika tidak memenuhi syarat kelulusan

## Cara Menjalankan
1. Jalankan file `main.py` dengan Python.
2. Masukkan nilai Tugas, UTS, UAS, dan persentase kehadiran.
3. Program menampilkan nilai akhir dan status mahasiswa.
